# 既知の制約（2026-08-03）

- ローカルの標準検証先はWSL2 PostgreSQLです。SQLite互換コードは旧画面・単体テスト用に残っていますが、複数端末運用の正本には使用しません。
- 商品画像APIはローカル/S3切替に対応しています。現在のローカル起動は`.data/uploads`であり、S3の実バケット、IAM、暗号化、署名URLはAWS適用後に確認します。
- パスワード再設定・通知メールはDBの送信待ちキューまでです。SES配送ワーカー、失敗再送、バウンス処理は未接続です。
- 為替レートは管理画面手入力です。外部レートサービスの自動取得は未実装です。
- 主要伝票の印刷と業務CSVは画面から利用でき、発行履歴もDBへ保存します。PDFファイル自体のサーバー生成・再ダウンロード保管は未実装で、現在の印刷はブラウザ印刷です。
- 監査ログは主要な管理・業務APIへ接続済みです。表示設定や補助操作までの完全網羅は継続課題です。
- TLS終端、WAF、IPレート制限、RDSバックアップ、Secrets Manager、CloudWatch監視、CI/CDはTerraform定義または運用設計段階で、実AWSには未適用です。
- 基準HTMLは正式な見た目としてReact入口から同一DOMへ直接読み込みます。iframeはありません。業務ロジックの一部は互換JavaScriptと`APP_DATA`投影を使用しますが、API接続時の正本はPostgreSQLです。完全なReactコンポーネント化は見た目を崩さない単位で継続します。

本番切替前に、AWS実環境、メール配送、バックアップ復元、同時操作、監査ログ、全帳票の受入試験を完了してください。
