# 既知の制約

- SQLiteを使用するため、単一アプリインスタンスでの運用を前提とします。複数ノードから同じDBへ書き込む構成は未対応です。
- TLS終端、WAF、ログイン・公開購入依頼へのIPレート制限はリバースプロキシまたは外部基盤で設定する必要があります。
- 商品画像はローカルファイルシステムへ保存します。複数ノード化にはオブジェクトストレージ対応が必要です。
- 為替レートは手入力またはCSVです。外部レートサービスの自動取得は未実装です。
- メール通知、承認通知、パスワード自己再設定は未実装です。
- バックアップの外部転送、暗号化、保持期限、定期実行は運用基盤側で設定します。
- 部分更新は`HX-Request`互換の軽量JavaScriptで実装しており、外部HTMXライブラリには依存していません。

これらは現行の確定要件に対するリリース阻害事項ではありませんが、本番インフラ設計と利用者手順へ反映してください。
