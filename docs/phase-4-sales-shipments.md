# フェーズ4 売上・出荷

完了日：2026-07-26

## 完了内容

- 売上伝票の下書き、確定、取消
- 出荷伝票の下書き、確定、取消
- 売上と出荷の独立登録
- 商品単位の売上明細・出荷明細関連付け
- 売上確定時の通貨、単価、数量、為替、換算金額の固定
- 売上済み・未出荷、一部出荷、出荷完了の表示
- 出荷先行時の「出荷済み・売上未確定」警告
- 売上確定後の出荷先行明細への自動割当
- 複数回出荷と分納残数
- 累計出荷数量のトランザクション内検証
- 売上・出荷取消時の割当、商品状態、出荷残数の再計算
- 組織スコープ、ルート単位の権限、監査ログ

## 状態

```text
売上：下書き → 確定 → 取消
出荷：下書き → 確定 → 取消
出荷進捗：未出荷 → 一部出荷 → 出荷完了
```

承認待ち状態のDB表現は用意していますが、金額閾値と承認実行はフェーズ6で接続します。

## 為替スナップショット

JPY売上は換算不要として確定金額を保存します。USD売上は確定時点の最新USD/JPYレートID、レート値、尺度、取得日時、JPY換算単価、JPY換算合計を売上明細へ保存します。

確定後に新しい為替レートを登録しても、確定済み売上は再計算しません。

## 分納と競合制御

出荷確定時に、同じ売上明細へ割り当て済みの累計数量と今回数量をトランザクション内で再集計します。売上数量を超える場合は出荷伝票を確定せず、明確な業務エラーを返します。

出荷を先に確定した場合は未関連のまま警告表示し、後から売上を確定すると数量検証後に自動関連付けします。

## 自動テスト

- AT-301：売上を先に確定
- AT-302：出荷を先に確定
- AT-303：売上済み・未出荷表示
- AT-304：一部出荷後の残数
- AT-305：複数回出荷と累計超過拒否
- AT-306：出荷済み・売上未確定警告
- AT-307：取消時の割当・商品状態再計算
- 確定為替スナップショットの不変性
- 組織スコープ
