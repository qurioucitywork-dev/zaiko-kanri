# フェーズ5 公開商品・購入依頼・取置

完了日：2026-07-26

## 完了内容

- 商品詳細からの公開・非公開設定
- 公開中かつ在庫中の商品だけを表示するゲストカタログ
- 原価・粗利・利益率を持たないゲスト専用商品モデル
- ワンタイムCSRF付き購入依頼フォーム
- 同一商品に対する複数の申請中依頼
- 購入依頼の社内一覧、承認、却下、取消
- 承認時だけ行う取置
- 商品ごとに1件だけの有効取置
- 取置期限のスナップショット保存
- 期限切れ、却下、取消時の取置解除
- 売上確定時の取置完了
- 商品状態と在庫イベントの連動
- 組織スコープ、権限制御、監査ログ

## 状態

```text
購入依頼：申請中 → 承認済み・取置中 → 売上化
                 ├→ 期限切れ
申請中／承認済み ├→ 却下
                 └→ 取消

商品：在庫中 → 取置中 → 販売済み
              └→ 在庫中（期限切れ・却下・取消）
```

## 競合制御

購入依頼送信では商品状態を変更しません。同一商品に複数の申請中依頼を保存できます。

承認時に商品状態を再確認し、`reservations`の部分一意インデックスと同一DBトランザクションによって、商品ごとの有効取置を1件に制限します。競合した承認は状態を変更せず、明確な業務エラーを返します。

## 取置期限

組織設定`reservation.duration_hours`が設定済みの場合はその値を使用します。未設定時の初期動作は24時間です。承認時に期限を固定し、購入依頼一覧・公開商品画面へのアクセス時にも期限切れを安全に反映します。

## ゲスト情報の保護

公開画面は`PublicProduct`専用モデルだけを使用し、原価、仕入先、粗利、利益率、内部在庫履歴を取得しません。購入依頼にはワンタイムCSRFトークンを使用します。

## 自動テスト

- AT-401：依頼送信だけでは取置しない
- AT-402：同一商品に複数の申請中依頼
- AT-403：承認時だけ取置
- AT-404：同時承認でも有効取置は1件
- AT-405：期限切れで自動解除
- AT-406：却下・取消で解除
- AT-407：売上確定で販売済み・取置完了
- ゲスト向けモデルの原価非保持
- 組織スコープ
