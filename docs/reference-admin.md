# 参照管理画面の固定仕様

## 参照元

- URL: `https://genspark.genspark.site/api/code_sandbox_light/preview/1759cf1a-6d3a-4298-bacb-39f05bacf441/app.html?canvas_history_id=d41d8e0b-6615-4fde-88d1-1450b163b4a8`
- 取得日: 2026-08-01
- 配置先: `frontend/public/admin-reference`
- ローカル表示: `http://127.0.0.1:8080/app/`

参照元のHTML、CSS、業務用JavaScriptを基準実装として保存する。2026-08-01の利用者指示による「相場表」は、
既存17画面を壊さないローカル拡張として`market-table.css`と`market_table.js`を追加し、`app.html`と`app.js`へ接続した。
Gensparkキャンバス用の外部検査スクリプトはファイル内に残すが、ローカル配信のCSPでは実行を許可しない。Font AwesomeとChart.jsは参照画面と同じCDNを許可する。
商品写真は参照元と同じ表示にするため、CSPの`img-src`に限って`https://sspark.genspark.ai`を許可する。

## デモ認証

- 管理者: `admin` / `admin123`
- 作業者: `buyer1` / `buyer123`（内部ロールキー`buyer`は旧プロトタイプ互換）
- ゲスト: `G001` / `guest123`

本番認証では使用しない。Go REST APIへ接続する際は既存のHttpOnly Cookie Sessionを利用する。

## 固定ハッシュ

`internal/web/reference_admin_test.go`に17ファイルのSHA-256を固定している。意図せず参照画面、ゲスト画面、相場表拡張が欠けたり、
ビルド成果物だけが古い状態になるとGoテストが失敗する。参照元を更新するときだけ、全画面比較後にハッシュを更新する。

## DOM操作契約テスト

`frontend/tests/reference-admin.test.mjs`は管理画面10本・ゲスト画面3本の業務スクリプトをブラウザ互換のDOMで実行し、次を検証する。

- 管理者ログインとセッション
- 18画面すべての遷移と、マスタ内サブ画面の切替
- サイドバーのアクティブ状態
- 商品詳細モーダルの表示
- 在庫一覧・商品詳細・編集・CSVで売価をUSD表示し、既存サンプルを固定レート155円で換算すること
- 相場表のUSD表示、行編集ポップアップ、CSV取込と価格反映
- BOX公開スナップショット、ゲストごとの公開商品制限、カート、購入リクエストと管理者通知
- ゲスト画面の375px対応を含むレスポンシブCSS契約
- HTML内の操作ハンドラーが存在する関数だけを参照していること
- 画面、ナビ、モーダルの件数

```powershell
cd frontend
pnpm run test:reference
```

## 実ブラウザ比較（2026-08-01）

相場表追加前の参照元とローカルを同じブラウザタブ・同じビューポートで順番に表示し、次を確認した。

- 1280×720のダッシュボード: PNGバイト列が完全一致
- 720×900のダッシュボード: PNGバイト列が完全一致
- サイドバー14項目: 各画面のタイトル、表示パネル、アクティブナビ、表件数、スクリーンショットがすべて一致
- 管理者ログイン: `admin` / `admin123`で両方とも同じ管理画面へ遷移
- 在庫一覧: 全件表示で10件を表示し、先頭商品の詳細モーダルを実クリックで開ける
- 商品詳細モーダル: 商品画像の読み込みを含めて0ピクセル差
- 720×900のモバイルメニュー: 開閉後のDOM状態とスクリーンショットが完全一致

画像CDNは`img-src`だけに限定し、`script-src`ではGensparkドメインを許可していない。
現在は利用者指示で左ナビに「相場表」を加えたため、参照元との差分としてこの1画面・1ナビ・1モーダルが意図的に存在する。

## React／REST APIへの置換状況

通常の`/app/`はReactを単一入口とし、ここに記載する基準画面を同一DOMへ直接マウントする。`ReferenceAdmin` iframe、`?mode=api`分岐、別デザインのReact業務画面は廃止した。基準画面の`api_bridge.js`がGo REST APIへ直接接続し、PostgreSQLを正本として再読込できる。互換JavaScriptは画面挙動を維持しながら段階的にReactコンポーネントへ移す。
