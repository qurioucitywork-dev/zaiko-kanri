# フェーズ3 相場・為替・価格計算

完了日：2026-07-26

## 完了内容

- ブランド・型番・商品種別単位の参考相場登録
- JPY・USDの相場価格
- UTF-8およびBOM付きCSVの一括取込
- ヘッダー、日付、通貨、価格、必須値の全行検証
- DB登録済みデータおよび同一CSV内の重複候補検出
- エラー行を含むCSVの確定禁止
- 最大5,000行、2MBの取込制限
- 管理者の即時確定
- 作業者の承認待ち登録
- USD/JPY為替レートの履歴保存
- 商品の参考相場、円換算額、粗利額、粗利率表示
- 組織スコープと操作権限

## CSV列定義

ヘッダー名と順序は固定です。

```csv
market_date,brand,model_number,product_type,price,currency,source
2026-07-26,グランドセイコー,SBGW301,腕時計,620000,JPY,店頭相場
```

取込はプレビュー用テーブルへ保存され、全行が有効な場合だけ確定できます。管理者は確定時に相場へ反映し、作業者は承認待ちになります。

## 為替と価格計算

為替レートは`1 USD = N JPY`を小数8桁相当の整数で保持します。新規登録時に既存行を更新せず、取得日時と取得元を含むスナップショットを追加します。

商品画面では最新の対象相場を参照し、USD相場は最新レートでJPYへ換算します。粗利額は`参考相場円換算額 - 仕入原価`、粗利率は参考相場円換算額に対する割合です。

売上確定時に採用した為替レートと金額を売上へ固定する処理は、売上機能を実装するフェーズ4で追加します。

## 外部接続

初期版は手入力とCSV取込のみです。外部相場API・為替APIとの自動連携は対象外です。

## 自動テスト

- 為替小数の整数化と履歴保存
- USD参考相場の円換算
- 粗利額・粗利率
- BOM付きCSV
- 不正ヘッダー・不正日付・不正通貨・不正価格
- DB内およびファイル内の重複候補
- エラー行を含むバッチの確定拒否
- 管理者確定と作業者承認待ち
- 組織スコープ
