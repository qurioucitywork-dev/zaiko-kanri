# フェーズ7実装報告：画面・部分更新・操作性

## 完了内容

- 在庫一覧のキーワード検索、状態フィルタ、6種類の並び替え
- 20件単位のサーバー側ページング
- 通常時に取消商品を除外し、管理者だけが取消商品を検索できる切替
- `HX-Request` に対応した在庫一覧の部分HTML応答
- 通常のGETフォームを維持したプログレッシブエンハンスメント
- 部分更新時も通常ルートと同じ認証、権限、CSRF検証を適用
- 部分更新の通信失敗・認証切れ・権限不足を安全な固定文言で表示
- 検索条件に一致する在庫・原価CSV出力
- CSV数式インジェクション対策とUTF-8 BOM
- 原価CSV出力の監査ログ記録
- 監査ログのキーワード、操作、結果フィルタ
- スキップリンク、フォーカス表示、見出し・表・ライブ領域のARIA改善
- モバイルメニューの開閉状態通知、フォーム二重送信防止

## 部分更新の設計

`GET /products` は通常リクエストではページ全体を返し、`HX-Request: true` の場合は `#product-results` だけを返します。どちらも同じハンドラ、組織スコープ、権限判定、検索条件を使用します。

画面は標準HTMLフォームを基準としているため、JavaScriptが無効でも検索、フィルタ、並び替え、ページ移動、CSV出力を利用できます。JavaScriptが有効な場合だけ、入力後の部分更新と履歴URL更新を追加します。React・Vueには依存していません。

## 受入確認

| ID | 確認内容 | 実装・テスト |
|---|---|---|
| AT-601 | JavaScript無効時も主要フォームを送信可能 | 標準GET/POST、全ページ応答テスト |
| AT-602 | 部分更新でも認証・認可・CSRFが有効 | ミドルウェア共通化、Webテスト |
| AT-603 | 部分更新エラーを安全に表示 | HTMLエスケープ済み固定エラー、Webテスト |
| AT-604 | 管理者が取消データを検索可能 | 取消除外・管理者切替、Webテスト |
| AT-605 | 原価CSV出力が監査ログに残る | CSV統合テスト |
| AT-606 | React・Vue非依存 | Goテンプレートと軽量JavaScriptのみ |

## DB変更

マイグレーション変更はありません。検索・並び替え・ページングは既存商品テーブルへの組織スコープ付きクエリとして実装しています。
